# MacroMap

A working prototype of Mostaque Tahamid's Entrepreneurship 3310 concept, built with AI assistance.

Browse 24 sample meals and 10 drinks, filter by budget and nutrition, compare items, save favorites, and build a meal with combined totals. Restaurant names, nutrition, caffeine, prices and distances are fictional.

Delivery and pickup links open external services to find real options; sample items are not transferred and no orders or payments are submitted by this prototype. Favorites and meal plans are stored locally in the visitor's browser.

## GitHub Pages

Publish the main branch from the repository root in Settings > Pages. The root contains index.html and .nojekyll, so no build step or API credentials are required.
